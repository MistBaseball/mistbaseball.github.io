## 최근 사용자 요청과 반영

사용자는 주루 방향 반대, 2루에 도착한 타자가 늦은 1루 송구로 아웃되는 문제, 플라이 아웃 누락, 투수의 구종별 움직임 범위를 지적했다. v03 코드에 네 항목과 관련 회귀 검사가 반영되어 있다. 수정 요청이 다시 오면 먼저 해당 테스트와 실제 증상을 비교한다.

1. `BASES` 좌표와 `playerYaw()`가 홈→1루→2루→3루 순서와 모델 전방을 일치시킨다.
2. `RunnerTrack`의 진루와 공/수비수의 도착 시간에 따라 합법적인 포스·태그를 판정한다.
3. 땅에 닿기 전 플라이 포구는 즉시 타자 아웃, 기본 귀루/대기 및 깊은 뜬공 태그업을 처리한다.
4. `pitchMovement()`를 궤적과 조준판이 공유한다. 표시 영역은 최종 도착 범위가 아니다.
